# Komplexní testovací plán — Přístav Radosti

## Základní problém stávajících testů

Existující E2E testy jsou **smoke testy** — načtou stránku a ověří nadpis. Nikdy nekliknou na
tlačítko a neověří, jestli to udělalo to, co mělo. Příklad:

```ts
// Stávající "booking" test — NESMYSLNÝ
test("4 — Booking flow", async ({ page }) => {
  await navigateTo(page, "/client/booking");
  const serviceCard = page.locator("button").filter({ hasText: /fyzioterapie/i });
  await serviceCard.click();
  // → ověří jen že se zobrazí krok s datem. KONEC.
});

// Co test MUSÍ dělat:
test("Klient dokončí rezervaci — termín se vytvoří, kredity se odečtou", async ({ page }) => {
  const balanceBefore = await apiGet(page, "/credits/balance");  // 4300 Kč
  // ... projde celý stepper ...
  await page.getByRole("button", { name: /Rezervovat|Potvrdit/i }).click();
  await expect(page.getByText(/Termín byl vytvořen|Rezervace potvrzena/i)).toBeVisible();
  // Termín se musí objevit v moje rezervace
  await page.goto("/client/appointments");
  await expect(page.locator("text=Fyzioterapie")).toBeVisible();
  // Balance se musí snížit
  const balanceAfter = await apiGet(page, "/credits/balance");
  expect(balanceAfter.data.balance).toBeLessThan(balanceBefore.data.balance);
});
```
