# Plán: Logo, přechody stránek, breadcrumbs

## Problémy k řešení

1. **Logo** — AnimatedLogo je příliš složité, na 20px vypadá špatně (přeplněné: kotva + maják + crossbar + stripe + lamp)
2. **Page transitions** — `y: 10` posun způsobuje "skákání boxů" při přechodu stránek
3. **Breadcrumbs na mobilu** — cesta (Home > Admin > ...) je na mobilu nevhodná

---

## 1. Logo — AnimatedLogo.tsx redesign

### Co odebrat
- Kompletně odstranit kotvu (ring, shaft, arms) z ikony
- Odebrat tmavý crossbar (`stroke="#242B61"`) — na bílém těle na tmavém pozadí to vypadá divně
- Zjednodušit tvar těla — méně bodů, čistší silueta

### Nový design (pouze maják, bold + čistý)
Ikona musí být čitelná na **20px** (mobile header) i **28px** (desktop sidebar).
Max 4 elementy:

```
viewBox 0 0 64 64, rendered na dark bg (bg-primary #242B61)

1. Tělo majáku — úzký obdélník + lehce lichoběžníkový tvar
   - Jednoduchý path: M26,50 L28,18 L36,18 L38,50 Z
   - fill="white"
   - Draw animace 0–0.6s

2. Střecha/cap — trojúhelník
   - M24,20 L32,8 L40,20 Z
   - fill="white"  
   - Draw animace 0.1–0.5s

3. Oranžový stripe — tenký pruh přes tělo
   - rect x=26, y=34, width=12, height=4, fill="#E86A24"
   - Fade in 0.35s

4. Lampa — zlatý kruh nahoře
   - cx=32, cy=10, r=4.5, fill="#FBBF24"
   - Fade in 0.4s → pak pulse smyčka (scale 1→1.12→1, 2s, Infinity)
   - Glow kruh za lampou: cx=32, cy=10, r=7, fill="#FBBF24", opacity=0.2 (bez animace)
```

### Animační sekvence (zůstává draw approach)
1. Tělo draw (0–0.6s)
2. Cap draw (0.1–0.5s, overlap s tělem)
3. Stripe fade-in (delay 0.35s)
4. Lampa fade-in (delay 0.4s), pak pulse loop
5. Celková pulse smyčka (delay po dokončení draw, scale 1→1.02→1)

### Co se NEMĚNÍ
- API komponenty: `AnimatedLogo({ size = 48 })` — stejné
- useReducedMotion guard — zachovat
- Exporty (named + default) — zachovat

### Vedlejší změna: logo.svg badge
Stávající `logo.svg` (circular badge) je OK na větších rozměrech (splash, manifest). Jelikož ale uživatel nechce kotvu v logu, odebrat kotvu i z `logo.svg` — tím se badge zjednoduší a bude konzistentní s novou ikonou.

## 2. PageTransition.tsx — pure fade

### Problém
```tsx
// STÁVAJÍCÍ — způsobuje skákání boxů
initial={{ opacity: 0, y: 10 }}
animate={{ opacity: 1, y: 0 }}
transition={{ type: "spring", stiffness: 380, damping: 32, mass: 0.8 }}
```

`y: 10` → obsah se posunuje o 10px nahoru při každém přechodu = "skákání boxů"

### Oprava
```tsx
// NOVÉ — čistý fade bez pohybu
initial={{ opacity: 0 }}
animate={{ opacity: 1 }}
transition={{ duration: MOTION.duration.short, ease: [0.2, 0, 0, 1] }}
```

Přidat import `MOTION` z `@/lib/motion`.

### AnimatedPages.tsx — stejná oprava pro konzistenci
`AnimatedPages` se v Layout nepoužívá přímo, ale pro konzistenci opravit také:
- Odebrat `y: 8` → zůstat pouze opacity fade

## 3. Breadcrumbs.tsx — skrýt na mobilu

### Oprava
Přidat `hidden md:flex` místo `flex` do className `<nav>`:

```tsx
// STÁVAJÍCÍ
className="flex items-center gap-1 text-sm ..."

// NOVÉ
className="hidden md:flex items-center gap-1 text-sm ..."
```

Tím se breadcrumbs zobrazí pouze na `md` a větším (≥768px).
